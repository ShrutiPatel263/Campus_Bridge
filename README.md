# 🎓 CampusBridge  
### Bridging the gap between juniors and placed seniors

CampusBridge is a **production-ready full-stack web platform** built to help students prepare for campus placements using **real interview experiences shared by placed seniors** — not guesswork, not random resources.

🚀 **Live Product**: https://campus-bridge-one.vercel.app  
👥 **10+ active real users and growing**

---

## 📌 Why CampusBridge?

As a student, I noticed a major problem in campus placements:

- Juniors don’t know **what companies actually ask**
- Preparation is often **unfocused and random**
- Real interview experiences are scattered across WhatsApp groups or lost completely
- Seniors want to help, but there’s **no structured platform**

**CampusBridge solves this by creating a single, open platform where experience turns into guidance.**

---

## 💡 What is CampusBridge?

CampusBridge is a **student-first platform** where:

- 🧑‍🎓 **Placed seniors** share real interview experiences  
- 📖 **Juniors** prepare smarter using authentic, peer-driven insights  
- 🔍 Content is searchable by **company, role, difficulty, and topics**
- 📊 Data is visualized using **interactive analytics dashboards**

> ⚠️ Juniors **do not need to sign up** — learning is frictionless  
> ✍️ Only seniors sign in, and only to contribute experiences

## 🛠️ Tech Stack

### Frontend
- React.js
- Tailwind CSS
- Chart.js / Recharts
- Deployed on **Vercel**

### Backend
- Node.js
- Express.js
- MongoDB
- JWT Authentication
- bcrypt for password hashing
- Deployed on **Railway**

### Architecture
- RESTful APIs
- Role-based access control
- Clean MVC structure

---

## 🧠 Thoughtful Design Decisions

- Juniors don’t need accounts → **no friction**
- Seniors authenticate only to contribute → **trust & accountability**
- Anonymous posting → **honest experiences**
- Analytics → **data-driven preparation**
